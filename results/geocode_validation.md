# SYN-002 지오코딩 좌표 품질 검증 (SYN-003)

데이터: SYN-002(`data/processed/geocode_cache.csv`, 34,640키) + 신규 표본 조회. 생성 코드: `src/validate_geocode.py`.
표본: 무작위 500개(seed=42). 카카오 API 호출 1,000건(주소 재조회 500 + 좌표→행정구역 역조회 500), 1,200건 제한 이내.

**사전 확인(2단계): `src/geocode.py`는 카카오 응답의 첫 번째 결과(`documents[0]`)를 그대로 쓰며, `address_type`을 저장하지 않는다.** 이 때문에 4~5단계에서 500건을 다시 조회해 address_type과 법정동 일치율을 구했다.

| 등급 | 키 수 | 전체 거래건수 | 직거래 제외 건수 |
|---|---|---|---|
| exact | 500 | 972 | 849 |
| unknown | 34,140 | 68,399 | 56,759 |

등급 기준: exact = address_type이 REGION_ADDR이고 법정동 일치(표본 내에서만 판단). region = address_type이 REGION이거나 같은 좌표를 공유하는 키가 20개 이상(표본 밖은 공유좌표 기준만 적용). unknown = 판단 불가. 이번 데이터는 고유 좌표 34,640개 = 전체 키 수(공유 좌표 0건)이므로 region 등급은 발생하지 않았다.
