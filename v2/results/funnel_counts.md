# v2 가격 모델 데이터 단계별 건수(funnel)

`v2/price_model.py`의 `load_v2_split()`, `v2_filter()`를 그대로 호출해 센 건수다. 모델은 다시 학습하지 않았고, 기존 결과 파일의 숫자도 바꾸지 않았다.

| 항목 | 건수 | 기간·조건 |
|---|---|---|
| 정제(SYN-001 전체) | 69,371 | 필터 없음, rh_trade_clean.parquet 전체 |
| 직거래 제외 후(direct_flag=0) | 57,608 | 정제 중 direct_flag=0만(상하위 1% 필터는 아직 적용 안 함) |
| 상하위 1% 제외 후(outlier_flag=0) | 67,983 | 정제 중 outlier_flag=0만(직거래 필터는 아직 적용 안 함) |
| 직거래·상하위1% 중복 제외 건수 | 302 | direct_flag=1 이고 outlier_flag=1 인 행(두 필터 모두에 걸림) |
| 학습(core) | 35,588 | 2024-11-01~2026-02월말(VAL_START 이전), v2 필터(직거래·상하위1% 제외) 적용 후 |
| 검증(val) | 10,046 | 2026-03-01~2026-05-31, v2 필터 적용 후 |

지표 종류: 행 건수. 임계값: 테스트(test) 건수가 7,561이 아니면 멈춤 — **통과(7,561)**. 집계 방식: `data/processed/rh_trade_clean.parquet`(69,371행)에 `src/features.py`의 `load_merged`+`build_features`를 적용한 뒤(좌표 결측 0건), `v2/price_model.py`의 `v2_filter`+`load_v2_split` 그대로 호출.

결과 파일: `v2/count_funnel.py` 콘솔 출력.
