# 데이터셋 명세 — npl-el

규칙: `docs/TRACKING_RULES.md`. 데이터 파일은 git에 올리지 않는다.
새 데이터를 쓰거나 만들기 전에 여기에 먼저 등록해 ID를 받는다.

## 목록

| ID | 이름 | 종류 | 용도 | 상태 | 로컬 위치 |
|---|---|---|---|---|---|

- 종류: 원본 / 파생 데이터 / 파생 뷰 / 테스트셋
- 상태: 사용 중 / 사용 중단 / 기각 / 미공개

## 항목 양식 — 원본(DS)
- 출처(논문·URL) / 라이선스·이용 약관 / 규모(대상 수, 샘플 수, 길이) / 형식·샘플링 / 라벨 / 무결성(해시) / 제외 항목 / 이상(불량 채널 등) / 사용 실험 / 주의

## 항목 양식 — 파생 데이터(SYN)
- 원본 ID / 생성 코드 경로 + 커밋 / 시드·파라미터 전체 / 출력 경로·샘플 수·크기·해시 / 검증 결과 / 알려진 문제 / 상태 / 사용 실험 / 이전 버전과 차이

## 항목 양식 — 파생 뷰(DV)
- 원본 ID / 변환 코드 경로 / 시드·파라미터 / 검증 결과(검증한 실험 ID) / 사용 주의

## 항목 양식 — 테스트셋
- 출처 / 사용 제한(학습 금지 등) / 공개 시점 / 알려진 정보
